# Security policy

## Supported versions

FluentBgWords is pre-1.0. Only the latest released minor version gets fixes, released as a new
patch version. `FluentBgWords` and `FluentBgWords.DependencyInjection` are released together
with the same version, so this applies to both.

| Version | Supported |
| ------- | --------- |
| 0.2.x   | Yes       |
| < 0.2   | No        |

## Reporting a vulnerability

Please don't report vulnerabilities in public issues. Report them privately through GitHub:
on the repository's **Security** tab, choose **Report a vulnerability**
([direct link](https://github.com/aleksandarMilev/fluent-bg-words/security/advisories/new)).

Include:

- the package (`FluentBgWords` or `FluentBgWords.DependencyInjection`) and its version;
- the .NET version;
- what the problem is and what an attacker could do with it;
- a minimal code sample or steps that reproduce it;
- a suggested fix, if you have one.

## What to expect

FluentBgWords is maintained by one person in their spare time, so there's no guaranteed
response time. You'll get a reply in the private report as soon as possible, and you'll be
kept informed there while a fix is prepared. Once a fixed version is on NuGet, the advisory is
published, with credit to you if you want it.
